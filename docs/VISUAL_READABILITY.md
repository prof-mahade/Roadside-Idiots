# Visual Readability Prototype

The graybox prototype is now too ambiguous for useful combat feedback. This pass keeps gameplay physics separate from presentation and adds a recognizable motorcycle, rider, and visible attack/hit reactions using locally imported prototype assets.

Local assets currently present on the development PC include UE Third Person Manny (`SKM_Manny_Simple`) and the Fab `MotoInteractionAnims` pack with `SM_Bike` plus Riding, Combat/Punch, Get_Hits, Dizzy, Mounted, and Interaction animations.

Recovery checkpoints should store a road-center safe point rather than the bike's exact crossing position.
